# 📦 Simulador Básico de Gestión Logística e Inventario

Este es mi primer proyecto práctico desarrollado en **Python** como estudiante de DAM. Es una herramienta de consola diseñada para simular la gestión operativa técnica de un almacén, aplicando lógica de programación a problemas del sector del transporte y la logística.

## 🛠️ Tecnologías utilizadas
*   **Lenguaje:** Python 3
*   **Conceptos aplicados:** Diccionarios de datos, estructuras de control (bucles y condicionales), funciones embebidas y uso de la librería estándar `time`.

## ⚙️ Características del script
1.  **Control de Stock:** Simula una base de datos en memoria para monitorizar productos, ubicaciones (zonas) y cantidades.
2.  **Actualización Dinámica:** Procesa órdenes de salida restando stock en tiempo real de forma segura.
3.  **Módulo de Rutas:** Simula un algoritmo básico para optimizar la prioridad de carga según la zona del almacén.
